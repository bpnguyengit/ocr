Architecture & Key Differences

  • DeepSeek-OCR / OCR-2: Heavy focus on input compression (few vision tokens per page). OCR-2 adds better visual causal flow for reading order. Excellent for single pages; KV cache grows with output length.
  • Unlimited-OCR: Builds on DeepSeek-OCR and replaces decoder attention with R-SWA. Keeps the KV cache constant regardless of output length. Enables stable one-shot transcription of dozens of pages (~30–40 under 32K context).
  • Falcon-OCR: Early-fusion design (image patches and text share the same Transformer from the first layer). Extremely small (~0.3B). Supports plain text / LaTeX / HTML table outputs via prompts. Highest throughput and lowest resource usage.

Summary Recommendation

  • Long multi-page documents in one pass with stable memory? → Unlimited-OCR (clear evolution of DeepSeek-OCR).
  • Original efficient optical-compression approach or slightly better single-page results? → DeepSeek-OCR-2.
  • Lightest, fastest, lowest-resource model that is still competitive? → Falcon-OCR (impressive at ~0.3B).

All three are open-weight and actively used. Real-world ranking depends on your exact document types (tables vs formulas vs handwriting vs multi-page length).
